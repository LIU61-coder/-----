Bergen 制度：四張高花配合架構

基本概念：當開叫 1M 時，從 2M 開始 +1 到 +5 的叫品，皆代表持有 4+ 張高花配合 (4+M fit)：

開叫 1H 後的 Bergen 答叫

  • 1H - 2♠! = 4+張H, 7~9點 有短
  • 1H - 2N! = 4+張H, FG (迫叫成局，三短四長)
  • 1H - 3♣! = 4+張H, 10~12點 有短
  • 1H - 3♦! = 4+張H, INV, BAL (均型邀請)
  • 1H - 3H = 4+張H, 阻擊或弱加叫 (NV: 0~6; V: 4~6)
  • 1H - 3♠ / 4X = 4+張H, 13~15點 有 S / X 短

開叫 1S 後的 Bergen 答叫

  • 1S - 2N! = 4+張S, 7~9點 有短
  • 1S - 3♣! = 4+張S, FG (迫叫成局，三短四長)
  • 1S - 3♦! = 4+張S, 10~12點 有短
  • 1S - 3♥! = 4+張S, INV, BAL (均型邀請)
  • 1S - 3S = 4+張S, 阻擊或弱加叫 (NV: 0~6; V: 4~6)
  • 1S - 4X = 4+張S, 13~15點 有 X 短

加奇數表示有短：開叫者「加一問短」後續

當答叫者做出代表有短的加叫時，開叫者可以使用「加一」的叫品來精確詢問答叫者的短門位置：

1H 開叫後續 (7~9點 / 10~12點有短)

1H - 2♠! (7~9有短) ➔ 2N! (加一問短)

↳ 3♣! = 梅花短 (short in C)

↳ 3♦! = 方塊短 (short in D)

↳ 3♥! = 黑桃短 (short in S)

1H - 3♣! (10~12有短) ➔ 3♦! (加一問短)

↳ 3♥! = 梅花短 (short in C)

↳ 3♠! = 方塊短 (short in D)

↳ 3N! = 黑桃短 (short in S)

1S 開叫後續 (7~9點 / 10~12點有短)

1S - 2N! (7~9有短) ➔ 3♣! (加一問短)

↳ 3♦! = 方塊短 (short in D)

↳ 3♥! = 紅心短 (short in H)

↳ 3♠! = 梅花短 (short in C)

1S - 3♦! (10~12有短) ➔ 3♥! (加一問短)

↳ 3♠! = 梅花短 (short in C)

↳ 3N! = 方塊短 (short in D)

↳ 4♣! = 紅心短 (short in H)

1H - 2N! 迫叫成局 (FG) 後續：開叫者描述

當進程為 1H - 2N! (三短四長強配合) 時，開叫者依手牌結構做出精準的回應與點力範圍描述：

開叫者 (Opener) 的再叫結構：

3♣ = 梅花短張 (short in C)

3♦ = 方塊短張 (short in D)

3♠ = 黑桃短張 (short in S)

4♣/♦/♠ = 5+張低花 / 6-5高花分配

3♥ = 平均牌型，12 - 15 點

3N = 平均牌型，16 - 18 點

4♥ = 平均牌型，19 - 21 點

1S - 3♣! 迫叫成局 (FG) 後續：開叫者描述

當進程為 1S - 3♣! (三短四長強配合) 時，開叫者依手牌結構做出精準的回應與點力範圍描述：

開叫者 (Opener) 的再叫結構：

3♦ = 方塊短張 (short in D)

3♥ = 紅心短張 (short in H)

3♠! = 梅花短張 (short in C) ※注意非自然

4♣/♦/♥ = 5+張低花或高花

3N = 平均牌型，12 - 15 點

4♠ = 平均牌型，16 - 18 點

4N = 平均牌型，19 - 21 點
