1m - 1M - 1NT 強度分類

目的在找尋最好的合約。因為同伴點力牌型都很限定，可以把自己的牌做一些強度分類：

1. 只有 partial 合約

看 1N / 2D / 2M / 3C 哪個好就選哪個。

2. 只有邀請的力量

分為 6M / 5M / bal / 5-4M / 5-5M 邀請。

3. 只有 game 的力量

找王牌配合或是打 3N。

4. 有滿貫興趣

找王牌配合或是詢問自己需要的東西。

2♣ (叫同伴轉換 2D)

基本概念：經過 2C! - 2D! 的過程比較弱。

開叫過程：1m - 1S ; 1N - 2C! ; 2D! - ?

弱牌止叫 (S/O)

  • Pass = D (留在 2♦ 合約)
  • 2♥ = 5-4+, S/O
  • 2♠ = 5+S, S/O

邀請力量 (INV)

  • 2NT = inv
  • 3X = 5-5, inv
  • 3♠ = 6+S, inv

直接叫牌路徑

不經過 2C!，在 1NT 後直接叫牌，代表更積極的牌力：

開叫過程：1m - 1S ; 1N - ?

迫叫成局 (FG)

2♦! = FG

直接叫 2D! 是強迫成局，要求同伴繼續描述牌型。

特定牌型邀請 (INV)

  • 2♥ = only 5-4, inv
  • 2♠ = only 5S, inv

滿貫試探與特殊 (ST)

  • 2NT! = puppet to 3C
  • 3X = 5-5, ST
  • 3♠ = 6+S, ST

1♣ - 1♠ 後續回答 (面對 2♦! FG)

當答叫者直接叫出 2♦! (FG) 時，開叫者的牌型回報：

1♣ - 1♠ ; 1N - 2D! ; ?

  • 2♥ = 4H but no 3S
  • 2♠ = 3S except 3334
  • 2NT = 3334
  • 3♣ = 5C, no 3S [2335]
  • 3♦ = 4D, no 3S [2245 / 1345] (5C)

1♦ - 1♠ 後續回答 (面對 2♦! FG)

與 1♣ 開叫相似，但在低花的分配上會有些微不同：

1♦ - 1♠ ; 1N - 2D! ; ?

  • 2♥ = 4H but no 3S
  • 2♠ = 3S except 3343
  • 2NT = 3343
  • 3♣ = 4C, no 3S [2344 / 2254 / 1354]
  • 3♦ = 5D, no 3S [2353]

進階 2NT Relay 與報控

1m - 1S ; 1N - 2D! ; 開叫者回答 2H/2S/2N/3C/3D 之後，答叫者可以：

1. 叫 2NT = Relay

要求同伴繼續表示牌型：

3m = 5+m

3om = 44+ / 43+

2. 叫花色 = 確立王牌

以這個花色作為王牌，同伴的再叫轉為報控（Cue-bid）。

實戰範例推演

1C - 1S ; 1N - 2D ; 2H - 2N ; ?

  • 3♣ = 1435 / 2425
  • 3♦ = 2434

1C - 1S ; 1N - 2D ; 2S - 2N ; ?

  • 3♣ = 3235 / 3325
  • 3♦ = 3145 (3334 is denied for 2S)
  • 3♥ = 4H
