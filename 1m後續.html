1♣ 開叫：一階答叫架構

當同伴開叫 1♣ 後，答叫者的回應可以依據「牌型」與「點力」作以下系統性分類：

均型與無王 (BAL)

  • 1NT = 6~10點
  • 2NT = 11~12點
  • 3NT = 3343 牌型, 16~18點
  • 4NT = 3343 牌型, 19~20點

思考題：持 3343 牌型，12~15點時怎麼叫？

答：先叫 1♦，隨後再叫 3NT。

自然叫品與弱牌

  • 1♦ = 5+張D, 6+點
  • 1M = 4+張M, 6+點
  • 2M = 6+張M, 5~7點 (only 2/3)

※ 2M 為弱牌阻擊，幫助確立牌型並干擾對手。

梅花配合與特約

  • 2♣ = 4+張C, 13+點 (反序低花)
  • 2♦ = 5+張C, inv (跳叫 om)
  • 3♣ = 5+張C, PRE (阻擊)
  • 3♦ / 3M = SPL (短門), strong ST
  • 4♣ = RKC [接下來用 4NT 問 K]

1♦ 開叫：一階答叫架構

1♦ 開叫的答叫邏輯與 1♣ 相似，但加入了二蓋一的元素，分類整理如下：

均型與無王 (BAL)

  • 1NT = 6~10點
  • 2NT = 11~12點
  • 3NT = 3334 牌型, 16~18點
  • 4NT = 3334 牌型, 19~20點

思考題：持 3334 牌型，12~15點時怎麼叫？

答：先叫 2♣，隨後再叫 3NT。

自然叫品與二蓋一

  • 1M = 4+張M, 6+點
  • 2♣ = 4+張C, 13+點 (二蓋一)
  • 2M = 6+張M, 5~7點 (only 2/3)

方塊配合與特約

  • 2♦ = 4+張D, 13+點 (反序低花)
  • 3♣ = 5+張D, inv (跳叫 om)
  • 3♦ = 5+張D, PRE (阻擊)
  • 3M / 4♣ = SPL (短門), strong ST
  • 4♦ = RKC

1m – 1♠; ? 開叫者再叫結構

當同伴答叫 1♠ 後，開叫者需根據「黑桃是否配合」、「點力多寡」及「牌型」進行明確的描述：

未配合 或 均型牌

  • 2m / 3m = 6+張m, 12~15點 / 16~18點
  • 2X = Reverse (逆叫), 5+張m + 4+張X, 16+點 (註: m < X < S)
  • 2NT = BAL, 無 4張S, 18~19點

一般配合 (4張黑桃)

  • 2♠ / 3♠ = 4張S, 12~15點 / 16~17點
  • 3NT! = BAL, 有 4張S, 18~19點
  • 4m = 6張m + 4張S, 16~18點
  • 4♠ = 6張m + 4張S, 19~21點

強配合與帶短門 (SPL) 特殊再叫

當持有 4 張黑桃配合且有特殊牌型時的高階再叫：

3♥!

4張S配合，帶有 單張 (19+點) 或 缺門 (16+點)。

4om / 4♥

4張S配合，該門 (om 或 H) 為 單張，點力介於 16~18點。
