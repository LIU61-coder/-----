2NT 開叫後的直接答叫架構

當同伴開叫強 2NT (20-21 HCP, 平均牌型) 時，答叫者的第一步決策與叫牌意義：

高花與結構性問叫

  • 3♣ = Stayman (保證至少一門 4 張高花)
  • 3♦ = Transfer to ♥ (5張以上紅心)
  • 3♥ = Transfer to ♠ (5張以上黑桃)
  • 3♠ = 5-4m 或 5+♣，問梅花配合度

成局與低花滿貫試探

  • 3NT = To play (止叫於 3NT)
  • 4♣ = 5+張 ♦ 滿貫試探 (Slam Try)
  • 4♦ / 4♥ = Texas Transfer (轉至 4♥ / 4♠)
  • 4♠ / 4NT = 量化問叫 (Quantitative) (佳/普通)
  • 5NT = 量化邀請滿貫 (Quant)

2NT - 3♣ (Stayman) 答叫與二階發展

開叫者根據有無 4 張高花做出回應，答叫者隨後可以進行滿貫試探或牌型再描述：

開叫者的第一步回應：

  • 3♦ = 無 4 張高花
  • 3♥ = 有 4 張紅心
  • 3♠ = 有 4 張黑桃

若開叫者答 3♦ (無高花)：

  • 3M = 4張M + 5張oM (高花 4-5 或 5-4 分配)
  • 4m = 5+張低花，滿貫試探 (ST)
    ※ 開叫人若無配合叫 4NT，有配合則報控
  • 4NT = 量化問叫 (Quant)

若開叫者答 3♥ / 3♠ (有高花)：

  • 面臨 3♥ 回應時：
  • 3♠ = Fit ♥，滿貫試探 (ST)
  • 面臨 3♠ 回應時：
  • 4♥ = Fit ♠，滿貫試探 (ST)
  • 共同後續：
  • 4m = 5+張低花，滿貫試探 (ST)
  • 4NT = 量化問叫 (Quant)

2NT - 3♦ / 3♥ (高花轉換) 與後續發展

轉換叫之後，答叫者可以選擇邀請滿貫（RKC）或帶出低花長門進行試探：

紅心轉換：2NT - 3♦ ; 3♥ - ?

  • 3♠ / 4m = 報控 (Cuebid)，確立 ♥ 為王牌
  • 4NT = ♥ RKC (羅馬關鍵牌問叫)
  • 3NT = 5張♥ 滿貫邀請，交由開叫者二選一：
  • 4m = 5張♥ + 4+張低花 (開叫者無配合回 4NT)
  • 4NT = 量化問叫

黑桃轉換：2NT - 3♥ ; 3♠ - ?

  • 4m / 4♥ = 報控 (Cuebid)，確立 ♠ 為王牌
  • 4NT = ♠ RKC (羅馬關鍵牌問叫)
  • 3NT = 5張♠ 滿貫邀請，交由開叫者二選一：
  • 4m = 5張♠ + 4+張低花 (開叫者無配合回 4NT)
  • 4♥ = 5-5 高花，非迫叫 (NF)
    (註：5-4M 會先經由 3♣ Stayman 詢問)
  • 4NT = 量化問叫

2NT - 3♠ (問梅花) 與 4♣ (方塊試探)

專門處理答叫者持有「低花長門」時的滿貫試探發展：

梅花尋覓：2NT - 3♠ ; ?

  • 3NT = 無 4 張梅花
  • → 續叫 4♣ = 5+張♣，滿貫試探
  • → 續叫 4♦ = 4+張♣ + 5+張♦，雙低花滿貫試探
  • → 續叫 4♥! = 6+張♣，強烈滿貫試探
  • 4♣ = 有 4+ 張梅花
  • → 續叫 4X = 報控 (Cue bid)，梅花滿貫確立

方塊滿貫試探與 4NT 後續

  • 2NT - 4♣ = 5+張 ♦ 滿貫試探 (Slam Try)
  • → 開叫人答 4NT = 無配合 (No fit)；其餘叫品 = 報控 (Cue-bid)
  • 2NT - 4NT = 量化問叫 (Quantitative)
  • → 後續發展與 1NT - 4NT 的配合原則完全相同。
