二蓋一 (Two-Over-One) 基本概念

核心精神：好牌慢慢叫。為了更好的迫局 (Game Forcing) 和滿貫試探，我們建立以下約定：

基本迫局約定

  • 1M - 2m = 4+張m, FG (1♦ - 2♣ 同理)
  • 1M - 2♥ = 5+張♥, FG

叫滿貫的標準步驟

  1. 找到配合： 保留滿貫試探 (ST) 叫品的空間。
  2. 報控制： 不能被對手直接提拔某門 AK。
  3. 問 A 確認： 確保我們不會缺兩張 Key Card。

1♠ – 2♦; ? 開叫者再叫結構

當答叫者以 2♦ 迫局後，開叫者的再叫需精確描述牌型與牌力：

Waiting 叫品

2♠! = Waiting

代表以下三種情況之一，暫時過渡以節省叫牌空間：

  • 5張♠，點力 12~15
  • 6+張♠，任何迫局點力
  • 4張♣，任何迫局點力

自然與均型再叫

  • 2♥ = 4+張♥
  • 2NT / 3NT = BAL (均型 5332), 16~18點 / 19~21點
  • 3♣ = 5+張♣ (雙低花 5-5+)

配合方塊與特殊牌

  • 3♦ = 配合♦ (4+張♦)
  • 3♠! = ♠ 堅強 (最多一失磴)
  • 3♥ / 4♣ = 配合♦, SPL (短門滿貫試探)
  • 4♦ = 配合♦, ST (滿貫試探)

SPL (Splinter) 與 1♥ 開叫特例

1♥ 開叫的二蓋一

進程：1♥ – 2♦; 2♠

2♠ = 4張♠

※ 答叫者叫 2♦ 並未否定有四張 ♠ (但通常不會有五張 ♠)。

什麼是 SPL (Splinter)？

跳叫新花色代表該門花色為單張或缺門，並同意同伴最後叫出的花色為王牌。希望該門沒有浪費的大牌力量。

  • 單張： 其餘三門共需約 27 HCP (大牌點) 即可打滿貫。
  • 缺門： 其餘三門共需約 23 ~ 24 HCP 即可打滿貫。

1♠ – 2♦ 進階後續與花色配合邏輯

明確花色長度再叫

  • 1♠ - 2♦;
  • 3♣ = 5+張♣ (牌型 5-5+)
  • 3♦ = 4+張♦

Waiting 後的進階釐清

  • 1♠ - 2♦; 2♠! -
  • 2NT = waiting, 無 3張♠
  • 3♣ = 5+張♦, 5+張♣
  • 3♦ = 6+張♦

若進程為：1♠ - 2♦; 2♠! - 2NT;
3♣ = only 4張♣
3♦ = only 3張♦

★ 1♠ – 2♦; 找配合的戰略邏輯 ★

對 梅花 (♣) 的配合

C 5-3： 開叫方主動拉 (叫出♣)

C 3-5： 答叫方主動拉 (叫出♣)

C 4-4： 先 waiting 後再拉 (尋找 4-4 配合)

對 方塊 (♦) 的配合

D 4-4： 直接配合 (叫出 3♦)

D 2-6： 答叫方拉第二次 (再叫♦)

D 3-5： 先 waiting 後再叫
