100 系統：滿貫試探架構

基礎定義

  • 1m - 1M - 4m/4M = 4張M配合, 6+張長m, 點力 16~18 或 19~21
  • 1m - 1M - 跳叫 oM = 4張M配合, 點力 16~18 (缺門) 或 19~21 (單缺)
  • 1m - 1M - 4om/4oM = 4張M配合, 該門單張, 16~18點 (限定牌型 SPL)

邀請與試探

若我方已有配合且僅有 12~15 點，使用 1m - 1M - 3M 進行邀請。

※ 針對跳叫 oM 的情況，因未指明哪一門短，同伴需額外進行詢問。

1♣ - 1♥ 進階後續

16-18 點區間

4D / 3S = 1張 方塊/黑桃

3H / 3S = 0張 方塊/黑桃

19-21 點區間 (透過詢問)

2S! - 2N! = 轉向詢問

3C / 3D = 1張 方塊/黑桃

3N / 4C = 0張 方塊/黑桃

1♣ - 1♠ 進階後續

16-18 點區間

4D / 4H = 1張 方塊/紅心

4D / 4H = 0張 方塊/紅心

19-21 點區間 (透過詢問)

3H! - 3S! = 轉向詢問

3N / 4C = 1張 方塊/紅心

4S / 4N = 0張 方塊/紅心
