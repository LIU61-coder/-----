反序低花 (Inverted Minor)

核心概念：二線強牌、三線弱牌。利用叫品強弱反轉，保留低線位進行滿貫試探。

約定規則

  • 1m - 2m = 4+張m, FG (Passed hand 為 only 4m, INV)
  • 1m - 跳叫 om = 5+張m, INV
  • 1m - 3m = 5+張m, PRE
  • 1m (X) 2N! = 5+張m, INV+, F1

思考題

問：同伴 1m 開叫，持 4+張m 迫局成局 (FG)，且帶有高花牌組，該叫 2m 還是 1M？

提示：這取決於高花是否有四張，以及能否在 FG 條件下順利尋找配合。

1m – 2m! 後續再叫

1C – 2C! 後續

  • 2D = 5+C + 4+D
  • 2M = 4張M
  • 2N = BAL, 12-14
  • 3C = 5+C, 16+
  • 3D/M = fit C, SPL
  • 3N = BAL, 18-19
  • 4C = RKC

1D – 2D! 後續

  • 2M = 4張M
  • 2N = BAL, 12-14
  • 3D = 5+D, 16+
  • 3M = fit D, SPL
  • 3N = BAL, 18-19
  • 4D = RKC

1D – 2C (二蓋一) 後續

2D! = Waiting (6+D, 12-15; 或 4M, 無5+D)

2M = 5D + 4M

2N = BAL, 12-14

3C = fit C (4+張)

3D = 6+D, 16+

3M! = fit C, SPL

3N = BAL, 18-19

特殊進程處理

1C – 2D 與 1D – 3C

1C - 2D;

  • 2M = stopper or suit
  • 2N / 3C = S/O (止叫)
  • 3D/M = short, CoG or ST (回應 4C=good)

1D - 3C;

  • 3D = S/O
  • 3M = short, CoG or ST (回應 4C=good)
  • 3N = S/O
